## Fantasy Guild UI Style Guide

### Version I · Dark Medieval Tavern

**Palette**

| Purpose | Color Name | HEX | Usage |
| --- | --- | --- | --- |
| Primary Background | Dark Forest Green | `#1C352D` | Main app background, header bar |
| Panel Backgrounds | Weathered Wood Brown | `#3B2A1E` | Player list panels, tournament cards |
| Accent Borders | Burnished Bronze | `#9C6B3E` | Card outlines, dividers |
| Highlight / Button | Dragonfire Gold | `#E7B45D` | Buttons, XP bars, icons |
| Text (Primary) | Parchment White | `#F4EBD0` | Titles, primary copy |
| Text (Secondary) | Ash Gray | `#B6AA96` | Subtitles, labels, tags |
| Error Button | Blood Red | `#802C2C` | Logout button, warnings |
| Success Button | Emerald | `#3C7A57` | Confirmation states, settings |

**Typography**

- Headers & titles: `Cinzel Decorative`
- Body/UI text: `Lora` or `Cardo`
- Buttons & stats: `Inter`

**Placement Notes**

- Background: Dark forest green base with a soft vignette.
- Panels: Weathered brown gradient, subtle wood grain overlay.
- Headers: Cinzel Decorative in parchment white.
- XP bars: Bronze outline, Dragonfire Gold fill.
- Buttons: Gradient from Dragonfire Gold to Burnished Bronze, parchment text.
- Borders/dividers: Burnished Bronze or very dark brown (`#2A1D12`).

### Version II · Vivid Emerald Guild

**Palette**

| Purpose | Color Name | HEX | Usage |
| --- | --- | --- | --- |
| Primary Background | Emerald Green | `#1F573D` | Page and navbar background |
| Panel Background | Warm Chestnut | `#5C331F` | Player and tournament containers |
| Accent / Lines | Goldleaf | `#D4A849` | Borders, highlights, icons |
| Highlight Glow | Amber Fire | `#F2B045` | Hover effects, XP bar fill |
| Text (Primary) | Ivory White | `#FFF5DC` | Headings, bright copy |
| Text (Secondary) | Sand Beige | `#D5C7A2` | Descriptions, UI labels |
| Error Button | Rustic Red | `#A93C32` | Danger actions |
| Success / Action Button | Jade Green | `#3F8758` | Primary actions |
| Shadow / Depth | Deep Olive | `#12261C` | Drop shadows, card edges |

**Typography**

- Logo & section titles: `Cinzel` (bold)
- Body text: `Merriweather`
- Buttons/HUD text: `Nunito Sans`
- Numbers/XPs: `Oswald`

**Placement Notes**

- Navbar: Emerald background with Goldleaf elements.
- Player cards: Chestnut panels, subtle inner shadow, amber hover highlights.
- Buttons: Jade to Gold gradient on hover.
- XP bar: Amber Fire fill with Goldleaf outline.
- Guild logo zone: Emerald base, Goldleaf border, soft glowing shadow.
- Tournaments section: Existing layout, parchment-toned text.

**Optional Embellishments**

- Add fine parchment grain to panels.
- Use candlelight gradients (amber to transparent) at panel edges.
- Sprinkle small gold sparkles near headers.
